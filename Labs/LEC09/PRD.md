# Sonic 애니메이션 뷰어 PRD

커밋할때 메시지는 반드시 한글로 한다.

## 1. 개요

`sonic-sprite.png`에 들어 있는 Sonic의 동작을 순서대로 재생하는 데스크톱 애니메이션 뷰어를 만든다. 프로그램은 Python과 pico2d를 사용하며, 구현은 `sonic_animation_viewer.py` 한 파일에 둔다.

이 문서는 `PRE-PRD.md`의 요구사항을 구체화하고, 1200 x 800 캔버스 크기와 이동 동작 조건을 반영한다.

## 2. 목표와 범위

### 목표

- 스프라이트 시트의 전체 10개 동작, 총 76프레임을 재생한다.
- 캐릭터 프레임을 원본의 4배 크기로 표시한다.
- 각 동작을 5회 반복하고 마지막 프레임에서 1초 정지한 다음 다음 동작으로 전환한다.
- 마지막 동작 이후 첫 동작으로 돌아가 전체 재생을 무한 반복한다.
- 이동 동작은 프레임 애니메이션과 동시에 화면상 위치도 변화시킨다.

### 범위 제외

- 키 입력으로 동작을 선택하거나 재생을 제어하는 기능
- 스프라이트 시트를 편집하거나 프레임 좌표를 화면에서 조작하는 기능
- 사운드, 점수, 게임 규칙 및 별도 설정 UI

## 3. 실행 환경

| 항목               | 결정 사항                                                      |
| ------------------ | -------------------------------------------------------------- |
| 언어 및 라이브러리 | Python, pico2d                                                 |
| 실행 파일          | `Labs/LEC09/sonic_animation_viewer.py`                       |
| 이미지 파일        | `Labs/LEC09/sonic-sprite.png`                                |
| 이미지 경로 기준   | 실행 작업 디렉터리를`Labs/LEC09`로 설정하고 상대 경로로 로드 |
| 캔버스 크기        | 1200 x 800 픽셀                                                |
| 출력 배율          | 원본 프레임 크기의 4배                                         |

## 4. 사용자 시나리오

1. 사용자가 `Labs/LEC09`에서 `sonic_animation_viewer.py`를 실행한다.
2. 1200 x 800 창이 열리고 첫 동작의 첫 프레임이 표시된다.
3. 뷰어는 동작별 프레임을 순서대로 재생한다. 이동 동작에서는 재생 중 캐릭터의 화면 위치도 함께 바뀐다.
4. 한 동작을 5회 재생한 뒤 마지막 프레임과 위치를 1초간 유지한다.
5. 다음 동작으로 자동 전환한다. 마지막 동작 뒤에는 첫 동작부터 다시 재생한다.
6. 사용자가 창 닫기 버튼을 누르면 이벤트를 처리하고 정상 종료한다.

## 5. 기능 요구사항

### FR-01: 초기화와 종료

- 1200 x 800 크기의 pico2d 창을 연다.
- `sonic-sprite.png`를 로드한다. 파일을 찾지 못하거나 읽을 수 없으면 원인을 알 수 있는 오류로 종료한다.
- 창 닫기 이벤트를 매 프레임 확인해 정상적으로 자원을 해제하고 종료한다.

### FR-02: 애니메이션 데이터

- 스프라이트 시트에 있는 모든 동작을 재생 순서대로 등록한다.
- 전체 동작 수는 10개, 전체 프레임 수는 76개여야 한다.
- 각 프레임은 스프라이트 시트 기준 잘라낼 사각형 좌표 `(left, top, width, height)`를 가진다.
- 프레임 데이터는 동작별로 관리하며, 실제 시트의 픽셀 좌표와 대조해 기록한다.
- 등록된 모든 프레임에 대해 좌표가 이미지 경계를 벗어나지 않는지 검사한다. 동작별 프레임 수의 합은 76이어야 한다.
- 동작 이름 및 이동 여부는 시트의 실제 구성을 확인해 등록한다. 근거 없이 프레임 좌표나 동작 이름을 추정하지 않는다.

### FR-03: 프레임 출력

- 해당 프레임 영역을 시트에서 잘라 캔버스에 그린다.
- 가로와 세로 모두 원본의 4배 크기로 출력한다.
- 캐릭터의 발 위치 또는 기준점이 프레임마다 불필요하게 흔들리지 않도록 프레임별 기준점을 보정한다.
- 출력 위치와 크기는 1200 x 800 캔버스 안에서 캐릭터가 잘리지 않도록 조정한다.

### FR-04: 프레임 재생

- 한 동작 안의 프레임을 순서대로 재생한다.
- 초기 프레임 간격은 0.1초로 두고, 실제 화면 재생을 확인해 필요하면 조정한다.
- 프레임 전환 시간은 경과 시간을 기준으로 계산해 실행 환경의 처리 속도에 따라 재생 속도가 크게 달라지지 않게 한다.

### FR-05: 반복과 정지

- 각 동작은 정확히 5회 반복 재생한다.
- 5회 재생이 끝나면 마지막 프레임을 표시한 채 1초간 정지한다.
- 정지 시간 동안 캐릭터의 화면 위치도 유지한다.
- 정지가 끝나면 다음 동작으로 전환한다.

### FR-06: 이동 동작

- 전체 10개 동작 중 이동이 포함된 8개 동작은 프레임 애니메이션과 화면 위치 이동이 동시에 진행되어야 한다.
- 이동 거리는 프레임 번호가 아니라 실제 경과 시간을 기준으로 계산한다.
- 수평 이동은 캔버스 경계 안에서 진행하고, 경계에 도달하면 이동 방향을 반전한다.
- 방향이 바뀔 때 캐릭터가 이동 방향과 어긋나 보이지 않도록 바라보는 방향을 함께 처리한다.
- 점프 동작에는 수평 이동과 독립적으로 확인 가능한 수직 궤적을 적용한다.
- 동작별 이동 속도와 점프 높이는 초기 구현에서 조정 가능한 값으로 두고, 실제 실행 결과를 보고 확정한다.

### FR-07: 제자리 동작

- 제자리에서 재생되어야 하는 2개 동작은 화면 중앙을 기준으로 재생한다.
- 해당 동작의 재생 중 캐릭터 위치를 이동시키지 않는다.

### FR-08: 전체 순환

- 동작 목록의 마지막까지 재생한 뒤 목록의 첫 동작으로 돌아간다.
- 프로그램은 창 닫기 이벤트가 발생할 때까지 순환을 반복한다.

## 6. 비기능 요구사항

- 프레임 출력, 시간 갱신, 이동 계산, 이벤트 처리를 구분해 코드를 읽고 수정하기 쉽게 한다.
- 프레임 전환과 캐릭터 이동은 실제 경과 시간에 기반해 계산한다.
- 이미지 또는 프레임 데이터 오류가 발생했을 때 잘못된 좌표를 조용히 출력하지 않고 원인을 파악할 수 있어야 한다.
- 불필요한 외부 라이브러리를 추가하지 않는다. pico2d 이외의 의존성이 필요해지면 먼저 이유를 검토한다.

## 7. 개발 및 검증 계획

개발은 한 번에 완성 코드를 작성하지 않고, 작은 변경을 구현하고 확인한 뒤 커밋한다. 과정 요구사항에 따라 의미 있는 단계별 커밋을 최소 20회 이상 남긴다. 커밋 개수만 채우기 위한 무의미한 변경은 하지 않는다.

| 단계       | 구현 및 검증 내용                                                            |
| ---------- | ---------------------------------------------------------------------------- |
| 1-4        | 실행 파일 골격, 1200 x 800 창, 이미지 로드, 종료 이벤트 처리                 |
| 5-8        | 동작 데이터 구조, 프레임 좌표 등록, 동작별 이름과 이동 여부 기록             |
| 9-12       | 전체 76프레임 수 검증, 이미지 경계 검사, 4배 출력, 기준점 보정               |
| 13-16      | 경과 시간 기반 재생, 동작별 5회 반복, 마지막 프레임 1초 정지, 다음 동작 전환 |
| 17-20 이상 | 이동 동작의 위치 변화, 경계 반전, 점프 궤적, 전체 순환 및 최종 실행 확인     |

### 완료 기준

- `Labs/LEC09`에서 실행했을 때 창과 스프라이트 이미지가 오류 없이 열린다.
- 10개 동작의 순서와 총 76프레임이 실제 스프라이트 시트에 맞는다.
- 모든 프레임 좌표가 시트 내부에 있고 캐릭터가 잘리지 않게 출력된다.
- 캐릭터가 4배 크기로 보인다.
- 각 동작이 5회 재생된 뒤 마지막 프레임과 위치를 1초간 유지하고 다음 동작으로 넘어간다.
- 이동 동작 8개는 애니메이션과 이동이 동시에 진행되고, 경계에서 방향이 반전된다.
- 제자리 동작 2개는 중앙에 머물며, 점프 동작은 수직 궤적을 보인다.
- 마지막 동작 뒤 첫 동작부터 반복되며 창 닫기로 정상 종료된다.
- 문법 검사, 시간/상태 흐름 검증, 실제 pico2d 창 실행 결과를 각각 확인한다. 한 종류의 확인만으로 나머지 검증을 대체하지 않는다.
